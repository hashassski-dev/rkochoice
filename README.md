# РКО Пульс

Готовый Netlify-проект сервиса сравнения РКО и банковских сервисов для бизнеса.

## Что внутри
- Темная и светлая темы с режимом «Система» по умолчанию.
- Черно-графитовый дизайн с красным акцентом.
- Локальные PNG-логотипы банков в карточках.
- Каталог с поиском, фильтрами ИП/ООО, РКО/РегБизнес и сортировкой.
- Bottom sheet с подробностями предложения.
- Админ-панель `/panel/` с одиночным и массовым редактированием карточек.
- Конструктор персональных страниц лидов `/panel/leads.html`.
- Отдельное Netlify Blobs-хранилище `rko-puls-showcase`.
- Публичная витрина не собирает ФИО/телефон/ИНН; оформление происходит на стороне банка/партнера.

## Локальный запуск
Используйте Netlify CLI, чтобы работали Functions:

```bash
npm install
npx netlify dev
```

Для публикации задайте переменные окружения авторизации панели согласно `SECURITY.md` / `README_GITHUB.md`.
