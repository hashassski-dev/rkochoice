# SEO контекст

Основная тема: сравнение расчетно-кассового обслуживания для ИП и ООО.

Основные запросы: расчетный счет для ИП, расчетный счет для ООО, РКО для бизнеса, открыть расчетный счет, сравнить тарифы РКО, бесплатное РКО, тарифы банков для бизнеса.

Перед публикацией замените YOUR-SITE.netlify.app в sitemap.xml на адрес, который выдаст Netlify. На главной уже есть title, description, Open Graph, robots и JSON-LD WebSite.

Не публикуйте партнерские выплаты и внутренние ЦД на публичных карточках. Эти поля есть в панели и посетителям не показываются.
